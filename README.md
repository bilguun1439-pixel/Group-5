# Assignment-2-Mid-Fidelity
Starter repository for CS 3307 Assignment 2 - Mid Fidelity, Fall 2026

## Functional Requirement Table
|Functional Requirement| Status|
|-----|-------|
|FR1: The user must be able to control the character using their keyboard. When the player presses the up, down, left or right arrows, the character in the game should move in the respective direction. |Not Done|
|FR2: The game must have a maze with doors in which the character can move up, down, left, or right to reach the exit.|Not Done|
|FR3: The game must start with a certain number of coins the player will use to unlock doors in the maze to reach the exit.|Not Done|
|FR4: If the player runs out of coins to open doors while playing the game, they must be able to go back through one of the doors they opened. When they go back through a door, the number of coins they used to open the door will be added back to their inventory, and the door will close behind them.|Not Done|
|FR5: There must be a timer showing how much time the player has left to reach the exit in the maze|Not Done|
|FR6: If the time runs out, the game should automatically display the path from the starting location to the exit that uses the number of available coins.|Not Done|
|FR7: There would be doors that give me the player coins when the player passes through it. In other words, passing through one of these doors would cause the number of coins to increase. If the player walks back through the door, then the number of coins the player has should decrease back down.|Not Done|
